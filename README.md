# Portfolio

A collection of academic and personal software projects, spanning **security, full-stack web, and cloud-native development**. Each project lives in its own folder with its own README and documentation.

---

## Projects

| Project | Description | Stack |
|---------|-------------|-------|
| [Secure Access Control System](./secure-access-control-system) | Simulation of a secure access-control system — card-based identity verification, OTP authentication, PIN/OTP data protection, and per-zone authorization. All logic built from scratch. | Python · Security · OTP |
| [TLK — Music Studio Booking](./TLK-Music-Studio) | Web application for booking music-studio sessions, built as a group academic project. | Java · Web |
| [SINAPP](./SignApp) | Java web application. | Java · Web |
| [BestBuy Cloud-Native Demo](./BestBuy-Cloud-Native-Demo-Application) | Microservices e-commerce demo on Azure Kubernetes Service with Service Bus + Azure Function order workflow. *(Also available as a [standalone repo](https://github.com/AhmedBoudouh/BestBuy-Cloud-Native-Demo-Application).)* | AKS · Docker · Azure |
